# 상품 리뷰 분석 에이전트 시스템 (Review Analysis Agent System)
> **"정성적인 고객 리뷰를 정량적 비즈니스 인사이트로 전환하기 위해, LangGraph 기반의 멀티 에이전트 워크플로우와 LLMOps 평가 체계를 구축한 프로젝트입니다."**

## 1. 프로젝트 개요
* **목표**: 대량의 상품 리뷰를 '속성(Aspect)-감성(Sentiment)' 단위로 자동 분석하고, 에이전트의 분석 품질을 검증하여 고객 Needs를 정량화
* **핵심 과제**: LLM 에이전트의 출력 신뢰성 확보(Quality Control) 및 대시보드 시각화
* **주요 성과**: 
    - Rule-based Critic Agent를 도입하여 에이전트의 지침 이행 여부를 자동 평가하는 파이프라인 구축
    - LangSmith를 활용한 실행 Trace 추적 및 실패 케이스 원인 분석 체계 마련
    - Streamlit 기반 실시간 리뷰 분석 및 시각화 대시보드 구현

---

## 2. 시스템 아키텍처 및 워크플로우
에이전트 간의 역할 분담과 반복적 피드백 루프를 통해 분석 품질을 향상시키는 구조로 설계했습니다.

| 단계 | 입력(Input) | 핵심 처리 로직(Processing) | 출력(Output) |
| :--- | :--- | :--- | :--- |
| **Supervisor** | 리뷰 데이터 | 분석 결과 기반 다음 Agent 라우팅 및 재시도 정책 결정 | 다음 Agent 지시 |
| **Analyzer** | 리뷰 원문 | 속성(Aspect) 추출 및 감성 분석(Sentiment) | JSON 분석 결과 |
| **Critic** | 리뷰 원문, 분석 결과 | Rule-based 기반 논리 일치성 및 품질 평가 | 검증 판정(Verdict) |

---

## 3. 핵심 기술 설계 (Engineering Insight)

### ① LLM 에이전트 고도화 (Supervisor 중심 반복 제어)
* **문제**: 초기 단일 에이전트 방식은 리뷰의 문맥을 전체적으로 파악하지 못하고, 특정 속성에 대한 판단이 모호한 경우가 잦았습니다.
* **해결**: **Supervisor 에이전트를 도입**하여 분석 전체 흐름을 제어했습니다. Critic 에이전트가 분석 결과를 부적합(Non-Conformity)으로 판정할 경우, Reason Code를 기반으로 Analyzer에게 구체적인 수정 지침(Repair Directive)을 전달하여 분석 품질을 반복적으로 향상시키는 **피드백 루프**를 설계했습니다.

### ② LLMOps 평가 환경 구축 (LangSmith 활용)
* **문제**: 에이전트의 분석이 '맞았는지'를 판단하는 기준이 모호했습니다.
* **해결**: **LangSmith Evaluator**를 도입하여 에이전트가 리뷰 원문과 분석 결과 사이의 논리적 일치성을 스스로 평가하도록 했습니다. 특히 `InterpretationType`을 분류하여 단순히 긍정/부정을 넘어선 고객의 의도(개선 요구, 혼합/애매 등)를 정교하게 파악했습니다.

### ③ 데이터 정합성 유지 (키값 충돌 방지)
* **해결**: 대량의 리뷰 데이터를 배치(Batch) 처리할 때 발생할 수 있는 데이터 중복 및 키값 충돌을 방지하기 위해, 데이터 저장소와 분석 결과가 1:1로 매핑되는 **DB 제약 조건 기반의 워크플로우**를 설계했습니다.

## 4. 리더십 및 협업 회고
* **기술적 조율**: 복잡한 에이전트 모듈들을 통합하는 과정에서 코드 컨벤션의 부재로 인한 병합 충돌을 방지하고자 팀 내 **코드 병합 규칙을 정립**하여 일관성을 유지했습니다.
* **리더십 발휘**: 프로젝트 중 방향성이 모호해지는 시점에 상황을 객관적으로 분석하고, 제한된 일정 내에서 달성 가능한 핵심 성과를 중심으로 **우선순위를 재설정**하여 팀이 흔들림 없이 목표를 향해 나아가도록 동력을 제공했습니다.
